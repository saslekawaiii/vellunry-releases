# Установка Vellunry

## Перед установкой

Скачивай файлы из раздела Releases этого репозитория. Исходники ZIP/TAR, которые
GitHub добавляет автоматически, содержат только оформление этой страницы;
это не установщики.

Для онлайн-каталога нужен интернет. Если не хочется устанавливать бета-клиент,
открой [vellunry.ru](https://vellunry.ru) в браузере.

## Android

1. Скачай файл с окончанием `-android.apk`.
2. Открой APK. Если Android попросит, разреши установку именно браузеру
   или файловому менеджеру, из которого ты открыл файл.
3. Запусти Vellunry. Приложение использует установленный браузер с поддержкой TWA.
4. Войди через Telegram или открой гостевой режим.

Это новый клиент с ID `com.vellunry.app`, он не заменяет старый экспериментальный
RknMusic Android. Не удаляй старое приложение, если в нём есть локальная музыка.
Без подходящего браузера возможен переход к обычной вкладке.

## Windows

1. Выбери EXE для x64 и запусти установщик.
2. Выбери папку установки и ярлыки.
3. Запусти Vellunry и войди в аккаунт.

У бета-сборки нет коммерческого сертификата подписи. Windows может показать
предупреждение о неизвестном издателе. Не отключай антивирус или системную
защиту целиком. Если установка заблокирована политикой компьютера, используй
веб-плеер и сообщи об этом в поддержку.

## macOS

1. В меню Apple открой «Об этом Mac». Для чипа Apple выбери `mac-arm64`,
   для процессора Intel — `mac-x64`.
2. Открой DMG и перенеси Vellunry в папку «Программы».
3. Запусти приложение.

Бета имеет локальную ad-hoc подпись, но не сертификат Developer ID и не
нотаризацию Apple. Системное предупреждение возможно. Не отключай Gatekeeper
глобально. Если система не разрешает запуск отдельного приложения,
используй веб-плеер до подписанного релиза.

## Linux

Для Debian/Ubuntu скачай DEB и установи его системным менеджером пакетов.
Другой вариант — AppImage:

```bash
chmod +x Vellunry-0.1.0-beta.1-linux-x64.AppImage
./Vellunry-0.1.0-beta.1-linux-x64.AppImage
```

AppImage может требовать FUSE. В этом случае предпочтительнее DEB на
совместимом дистрибутиве. Не запускай плеер от root и не отключай sandbox.

## iPhone и iPad

IPA в этом релизе **не подписан для прямой установки**. Обычным нажатием
в Safari он не установится.

1. Скачай `-ios-unsigned.ipa` на компьютер.
2. Используй Sideloadly или AltStore для подписи своим Apple ID и установки
   на своё устройство. Следуй инструкции выбранного инструмента.
3. После установки запусти Vellunry и войди в аккаунт.

Срок действия подписи и необходимость её обновления зависят от типа твоего
аккаунта Apple и выбранного инструмента. Apple ID, пароль и коды подтверждения
не передавай поддержке Vellunry.

Без переподписи доступна PWA: открой сайт в Safari и выбери
«Поделиться → На экран Домой».

## Проверка файла

В релизе есть `SHA256SUMS.txt`. Сравни хеш скачанного файла со строкой для
него в этом списке. Примеры:

```powershell
Get-FileHash .\Vellunry-0.1.0-beta.1-win-x64.exe -Algorithm SHA256
```

```bash
shasum -a 256 Vellunry-0.1.0-beta.1-mac-arm64.dmg
```

Совпадение хеша подтверждает целостность файла, но не заменяет подпись издателя.
